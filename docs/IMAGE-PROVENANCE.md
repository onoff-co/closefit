# 이미지 출처와 사용 정책

외부에서 다운로드한 인물·상품·배너 사진은 현재 소스와 배포 자산에서 제거했습니다. 실제 인물 사진이나 레퍼런스 상품 사진을 이미지 생성의 참조 입력으로 사용하지 않았습니다.

| 파일 | 출처 / 용도 |
|---|---|
| closefit-logo.png | 사용자가 제공한 브랜드 로고 |
| hanger-shirt.png | 내장 image_gen으로 새로 생성한 셔츠 |
| hanger-catalog.png | 내장 image_gen으로 새로 생성한 의류 8종 콘셉트 |
| ai-autumn-model.png | 내장 image_gen으로 새로 생성한 가상의 성인 AI 모델, 메인 캠페인 |
| ai-textile-closeup.png | 내장 image_gen으로 새로 생성한 제품 원단 클로즈업, 에디토리얼 배너 |

메인 인물은 실존 인물의 사진을 재사용한 것이 아닙니다. 모든 생성 이미지는 AI 콘셉트로 실제 상품 촬영물이 아닙니다. 관리자 상품 이미지 선택도 승인된 생성 상품 이미지로 제한합니다. 기존 데이터베이스에 저장된 옛 이미지 경로는 API 응답에서 생성 이미지로 정규화하여 노출합니다.

생성 도구는 기본 내장 image_gen.imagegen이며 프롬프트와 참조 이미지 미사용 기록은 public/assets/image-provenance.json과 ASSET-PROMPTS.md에 남겼습니다.

자동 테스트는 승인된 이미지 파일 목록, 제거된 자산의 부재, 상품 이미지 검증·정규화를 확인합니다.
