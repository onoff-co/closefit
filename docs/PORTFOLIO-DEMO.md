# 포트폴리오 데모 전환

목적: 고객사가 가입·로그인·로그아웃·상품 관리·회원 관리·주문 관리·결제를 예시 데이터로 체험한다.

- 정적 React 앱으로 GitHub Pages에서 실행한다.
- 모든 /api 계약은 브라우저 목업 어댑터가 처리하며 운영 API·DB에 요청하지 않는다.
- 고객·관리자 예시 계정 전환, 닉네임만 받는 가상 가입, 브라우저에 유지되는 세션을 제공한다.
- 상품·회원·주문 CRUD는 방문자 본인의 localStorage에만 반영한다.
- 초기 예시 주문·회원·방문 통계와 초기화 기능을 제공한다.
- 결제는 상품 확인 → 가상 수단 선택 → 결제 완료 → 마이페이지 주문 조회 흐름이다. 카드번호·주소·비밀번호를 수집하지 않는다.
- 관리자 권한은 체험 화면의 역할 전환이며 보안 인증이 아니다.
- HashRouter와 배포 base 경로로 /closefit/#/ 경로 및 새로고침을 지원한다.
- GitHub Actions에서 테스트·정적 빌드 후 Pages에 배포한다.
- 기존 worker/와 drizzle/는 이전 백엔드 참고 코드로 보존하며 Pages에서는 실행하지 않는다.

검증: 예시 가입·역할 전환·로그아웃·결제·중복 결제 방지·권한별 목록·관리 CRUD·초기화·정적 자산 하위 경로 및 Actions 결과.
